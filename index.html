What this is: a cart that can only push itself left/right, carrying two pendulum links joined end to end. Left alone, it's chaotic and falls — same class of problem as balancing a broom on your palm, except now the broom has an elbow. The equations of motion are derived from the actual Lagrangian of the system (mass matrix, Coriolis and gravity terms, solved every physics step), not a canned animation. The controller reads all six state variables (cart position/velocity, both angles, both angular velocities) and computes a single push force — gains found by solving the linear-quadratic regulator for this system rather than hand-tuned — that's the Reference controller mode. Switch to Manual PID to type in your own Kp/Ki/Kd for each link and the cart, all starting at zero, and watch it fall until you find gains that work. Load reference gains fills the fields with the same numbers the reference controller uses, re-expressed as three per-joint PID terms, so you can see what "correct" looks like and perturb from there. Click and drag the top bob to disturb it mid-simulation, or use Kick for a clean impulse. Push it too far and it'll fall — that's real, not scripted.
